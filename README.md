# The Silent Co-Driver: Motorsport Telemetry & Tactical Engineering Cockpit

## Project Overview
The Silent Co-Driver is a cutting-edge web application designed for high-performance motorsport and endurance racing. It provides a next-generation tactical telemetry and AI co-driver instrumentation interface, offering real-time data visualization, AI-driven race radio analysis, and post-session debriefing capabilities.

## Features
-   **Live Cockpit (`index.html`)**:
    -   Real-time telemetry rendering including speed, RPM, gear, G-forces, pedal inputs, and tire data.
    -   Interactive canvas-based visualizations: digital tachometer, G-force radar, and AI audio waveform.
    -   AI Co-Driver advisory stream providing tactical messages and real-time insights.
    -   Dynamic vehicle parameter adjustments (Brake Bias, Engine Map, Differential Entry).
    -   Session mode switching (Race, Qualifying, Wet/Safety Car).
-   **Race Radio Analyzer (`race_radio.html`)**:
    -   AI-driven race radio transcription and audio telemetry ingestion.
    -   Driver stress detection and acoustic parameter correlation.
    -   Simulated live recording and audio file upload capabilities.
-   **Analysis Result (`analysis_result.html`)**:
    -   Detailed AI debrief of race radio sentiment analysis and stress index.
    -   Correlation of voice acoustic parameters with telemetry deltas.
    -   Actionable recommendations based on AI analysis.


## Technologies Used
-   **Frontend**: HTML5, CSS3 (with Tailwind CSS via CDN), JavaScript
-   **Canvas API**: For high-performance real-time data visualization.
-   **Google Fonts**: Inter and JetBrains Mono for typography.
-   **Material Symbols Outlined**: For iconography.
